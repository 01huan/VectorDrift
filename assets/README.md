# Vector Drift assets

The game runs fine with these folders empty: every missing file is just silent.
Drop in CC0 (public domain) files and rename them to the slot names below.
Each slot tries `.ogg`, then `.wav`, then `.mp3`.

## Sound effects: `assets/sounds/`

| File name (no extension) | When it plays | Suggested source (CC0) |
|---|---|---|
| `click` | Any button press | Kenney *Interface Sounds* |
| `error` | Clicking Launch while a formula is invalid | Kenney *Interface Sounds* |
| `launch` | Ship launches | Kenney *Sci-fi Sounds* |
| `thruster_loop` | Loops during flight (optional, should loop seamlessly) | Kenney *Sci-fi Sounds* |
| `life_lost` | Time up / out of bounds / diverged / aborted | Kenney *Sci-fi Sounds* |
| `win` | Ship reaches the target | Kenney *Music Jingles* |
| `game_over` | Last life lost | Kenney *Music Jingles* |
| `shield_break` | The shield breaks on the first rock it touches | Kenney *Sci-fi Sounds* |

## Music: `assets/music/`

| File name | When it plays |
|---|---|
| `bgm` | Loops in the background (optional). Search OpenGameArt.org filtered by license "CC0". |

## Fonts: `assets/fonts/` (optional)

| File name | Used for | Fallback |
|---|---|---|
| `ui.ttf` | Labels and body text | Segoe UI / Arial |
| `ui_bold.ttf` | Titles and buttons | Segoe UI Semibold |
| `mono.ttf` | Formula boxes and numbers | Consolas |

## Where to get them

- Kenney: https://kenney.nl/assets (all packs are CC0, attribution optional)
- OpenGameArt: https://opengameart.org (filter by license, pick CC0)

Mute anytime with **Ctrl+M** or the *Sound* button in the bottom-right corner.
